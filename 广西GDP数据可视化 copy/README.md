# 广西各市GDP数据可视化课程设计

## 项目简介

本项目是基于ECharts的广西各市GDP数据可视化课程设计，旨在通过交互式图表展示广西14个地级市2025年季度GDP数据的变化趋势和分布情况。

## 项目特点

- 📊 **多图表展示**: 包含饼图、柱状图、折线图等多种图表类型
- 🔗 **图表联动**: 实现多图表之间的交互联动
- 🎨 **美观界面**: 采用现代化UI设计，响应式布局
- 📱 **移动友好**: 适配各种屏幕尺寸
- 🔄 **动画效果**: 丰富的过渡动画和交互动画
- 💾 **本地运行**: 无需网络连接，本地ECharts库

## 功能特性

### 1. 图表展示功能
- **饼图**: 展示各市GDP占比分布，支持季度切换
- **混合图表**: 柱状图+折线图展示GDP总量与增长率变化
- **数据联动**: 点击饼图区块联动更新混合图表

### 2. 交互功能
- **季度选择器**: 动态切换不同季度的GDP分布
- **城市选择器**: 选择查看不同城市的详细趋势
- **图表导出**: 支持将图表导出为PNG图片
- **视图重置**: 一键重置图表视图状态
- **图表切换**: 支持混合图和折线图切换

### 3. 数据功能
- **异步加载**: 模拟异步数据加载效果
- **数据更新**: 动态更新统计摘要数据
- **数据验证**: 完善的数据验证和错误处理

## 技术栈

- **前端框架**: 原生HTML5 + CSS3 + JavaScript
- **图表库**: ECharts 5.4.3
- **数据处理**: JavaScript对象存储和操作
- **样式方案**: 自定义CSS，无外部依赖

## 快速开始

### 步骤1：下载项目文件
1. 下载本项目的所有文件到本地
2. 确保文件结构完整

4. 使用城市选择器切换不同城市

## 故障排除

### 常见问题
1. **图表不显示**
   - 检查 `echarts.min.js` 是否已下载
   - 检查文件路径是否正确
   - 查看浏览器控制台错误信息

2. **数据加载失败**
   - 检查网络连接（如需从CDN加载）
   - 检查数据文件完整性

3. **交互无响应**
   - 检查浏览器是否支持ES6+
   - 检查JavaScript控制台错误

### 调试方法
1. 按F12打开开发者工具
2. 查看Console面板的错误信息
3. 检查Network面板的资源加载
4. 查看Application面板的存储状态
