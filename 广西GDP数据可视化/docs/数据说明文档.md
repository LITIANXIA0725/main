# 广西各市GDP数据说明文档

## 项目概述
本文档旨在说明《广西各市GDP数据可视化课程设计》项目中使用的数据来源、数据处理流程以及数据质量情况。

## 一、数据来源

### 1.1 原始数据文件
- **文件名**: `各市季度数据.pdf`
  - **内容**: 广西14个地级市2024-2025年季度GDP累计增长率数据
  - **时间范围**: 2024年全年至2025年前三季度
  - **指标**: 地区生产总值_累计增长(%)

- **文件名**: `广西GDP_2025年季度累计值_聚汇数据.pdf`
  - **内容**: 广西及各市2025年季度GDP累计值数据
  - **时间范围**: 2025年一季度至三季度
  - **指标**: GDP累计值（亿元）

### 1.2 数据获取方式
- **获取时间**: 2024年5月
- **获取渠道**: 从公开数据网站下载PDF文件
- **数据时效性**: 最新数据至2025年三季度

## 二、数据处理流程

### 2.1 AI数据提取
原始PDF文件 → AI工具处理 → 结构化数据表格


**使用工具**: 智能文档处理工具（如OCR+表格识别）
**处理步骤**:
1. 上传PDF文件到AI处理平台
2. 识别表格结构和数据内容
3. 提取表格数据为结构化格式（JSON/CSV）
4. 验证数据准确性

### 2.2 数据清洗与转换

#### 2.2.1 数据格式标准化
- 统一城市名称格式（如"南宁"统一为"南宁市"）
- 统一数值格式（去除千分位，统一小数位数）
- 统一时间格式（"2025年前三季度" → "2025年三季度"）

#### 2.2.2 缺失值处理
**问题**: 钦州市2025年一季度GDP数据在原始数据中缺失
**处理方法**:
1. 分析钦州市GDP增长趋势
2. 参考二季度数据（835.99亿元）和增长率（6.3%）
3. 使用趋势外推法估算：`417.37亿元`
4. **标注说明**: 在可视化中明确标注该数据为估算值

#### 2.2.3 数据验证
- **完整性检查**: 验证14个城市、3个季度的数据完整性
- **一致性检查**: 验证增长率与累计值之间的逻辑关系
- **异常值检查**: 检查是否存在明显异常的数据点
